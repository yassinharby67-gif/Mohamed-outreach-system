# Local Data Policy

هذا الملف يشرح السياسة فقط. **لا تضع بيانات العملاء أو الشاتات أو الـLeads الحقيقية داخل مجلد `data/` أو داخل Repository.** خزّنها خارج فولدر الريبو تمامًا.

`.gitignore` يساعد على منع الملفات الجديدة غير المتتبعة في الوضع العادي، لكنه لا يحمي ملفًا متتبعًا بالفعل ولا يمنع `git add -f`. لذلك التخزين خارج الريبو هو القاعدة الأساسية، و`.gitignore` طبقة أمان إضافية فقط.
