# Privacy

الـRepository الحالية **Public بقرار ياسين**. أي شخص يقدر يشوف أو يستنسخ الملفات. تغيير الخصوصية قرار يرجع لياسين، وليس خطوة ينفذها النظام تلقائيًا.

## لا ترفع

- شاتات خام.
- أسماء كاملة أو أرقام أو إيميلات.
- روابط حسابات حقيقية.
- IDs خاصة أو روابط Google Drive/Sheets حقيقية.
- كلمات مرور أو API Keys أو Tokens.
- بيانات Leads أو CRM حقيقية.

## سياسة التخزين

بيانات العملاء والشاتات الحقيقية تتخزن خارج فولدر الـRepository تمامًا. مجلد `data/` موجود للتوثيق فقط، وليس مكانًا لوضع البيانات الحقيقية.

قاعدة `.gitignore` تساعد في منع الملفات الجديدة غير المتتبعة من الدخول في Git في الوضع العادي، لكنها لا تؤثر على ملف متتبع بالفعل، ولا تمنع إضافة ملف بالقوة باستخدام `git add -f`. لذلك `.gitignore` طبقة أمان إضافية وليست بديلًا عن سياسة التخزين خارج الريبو ومراجعة المحتوى يدويًا قبل كل Commit أو Push.

## جمع البيانات

استخدم أقل قدر لازم من البيانات العامة المرتبطة بالعمل. لا تستنتج الجنسية أو البلد من الاسم أو الشكل. إذا لم يمكن التحقق من مصدر، اكتب `غير متحقق` أو `غير مؤكد` حسب قائمة الحالات في `docs/status-list.md`.
