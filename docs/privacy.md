# Privacy

الـRepository خاص لكنه ليس مكانًا للبيانات الحساسة.

## لا ترفع

- شاتات خام.
- أسماء كاملة أو أرقام أو إيميلات.
- روابط حسابات حقيقية.
- IDs خاصة أو روابط Google Drive/Sheets حقيقية.
- كلمات مرور أو API Keys أو Tokens.
- بيانات Leads أو CRM حقيقية.

## تخزين محلي

ضع البيانات الحقيقية خارج جذر الـRepository، مثل مجلد محلي غير متتبع. استخدم `.gitignore` كطبقة مساعدة فقط، ثم راجع محتوى الملفات يدويًا قبل أي Commit أو Push.

## جمع البيانات

استخدم أقل قدر لازم من البيانات العامة المرتبطة بالعمل. لا تستنتج الجنسية أو البلد من الاسم أو الشكل. إذا لم يمكن التحقق من مصدر، اكتب `غير متحقق منه`.
