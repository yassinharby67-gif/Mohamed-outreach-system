# Unified Status List

هذه هي قائمة الحالات الوحيدة المستخدمة في الملفات والقوالب. لا تستخدم أسماء بديلة مثل `Draft` أو `Reply Pending` أو `Ghosted` في بيانات التشغيل؛ استخدم الاسم الموحد هنا.

| الحالة الموحدة | المرحلة | المعنى | CRM/Sheet mapping |
|---|---|---|---|
| RAW_COLLECTED | جمع | سجل خام أُنشئ من مصدر عام | اسم العمود الفعلي غير متاح، يحتاج قراءة وموافقة |
| MISSING_REQUIRED_DATA | جمع | Instagram أو Website مفقود أو غير مؤكد | يحتاج تحديد عمود الحالة الفعلي |
| VERIFICATION_PENDING | تحقق | التحقق لم يكتمل | يحتاج تحديد عمود الحالة الفعلي |
| VERIFIED | تحقق | الهوية والمصادر الأساسية متحققة | يحتاج تحديد عمود الحالة الفعلي |
| UNVERIFIED | تحقق | الدليل غير كافٍ، وليس حكمًا بعدم الملاءمة | يحتاج تحديد عمود الحالة الفعلي |
| QUALIFIED | تأهيل | اجتاز الشروط المؤكدة في Batch Config | يحتاج تحديد عمود الحالة الفعلي |

| NEGATIVE_REPLY | الردود | رفض صريح | يحتاج تحديد عمود الحالة الفعلي |

## أسئلة Mapping المفتوحة

- ما أسماء أعمدة الحالة الفعلية في الشيت؟ غير متاح، ويجب قراءتها وعرضها لياسين قبل أي كتابة.
- هل يوجد عمود منفصل لنوع الأصل، أو تاريخ آخر إجراء، أو رابط الرسالة؟ غير متاح.
- لا يجوز إضافة أو تغيير أعمدة بناءً على هذا الملف وحده.
