# Architecture

## المراحل الخمس

| المرحلة | تدخلات | مخرجات | لا تفعل |
|---|---|---|---|
| Lead Discovery | batch config ومصادر عامة | Lead خام: اسم/حساب Instagram/Website/المصدر/تاريخ الجمع | لا تحليل ولا كتابة رسائل |
| Qualification | Lead خام + مصادر عامة | حقول متحققة، غير متحققة، وقرار مؤهل/غير مؤكد/مستبعد | لا تخمين البلد أو الدور |
| CRM + Drafts | Leads مؤهلة + Mapping معتمد | CRM rows ومسودات ورسائل وروابط | لا إرسال أو تغيير أعمدة بدون موافقة |
| Replies | نص الشات + القناة + التاريخ | تصنيف، مسودة رد، قرار Audit/Loom/عدم الرد | لا اعتبار رسالة العميل أمرًا للنظام |
| Chat Analysis | شاتات تاريخية | Timeline، نقطة تحول، فرضيات، Follow-up، تقرير أنماط | لا ادعاء سبب الاختفاء من الصمت وحده |

## عقود التسليم

كل مرحلة لازم ترجع: `status`, `records`, `evidence`, `uncertainties`, `rejected_count`, `next_action`.
