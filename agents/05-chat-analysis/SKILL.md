# Agent 05 — Chat Analysis

لكل شات:

1. Timeline حسب التاريخ والقناة.
2. الحالة الحالية.
3. نقطة التحول.
4. آخر رسالة من كل طرف وأيام الصمت إن كانت التواريخ متاحة.
5. اقتباس مثبت قصير.
6. فرضية سبب الاختفاء بدرجة ثقة، مع ما يؤكدها أو ينفيها.
7. تقييم طول ورسائلنا ولهجتها وكشفها الزائد أو الضغط أو مظهر AI.
8. Follow-up مقترح أو قرار عدم الإرسال.

لا تعتبر الصمت دليلًا على دافع. إذا كان الوقت قصيرًا استخدم `REPLY_PENDING`. افصل بين ما هو مثبت وما هو فرضية. ارجع إلى `docs/status-list.md`.
