# Google Docs Tabs Procedure

الافتراضي التشغيلي حسب طلب ياسين: مسودة كل عميل في Tab خاص به داخل Google Doc، ورابط الـTab يتسجل في عمود `message-link` في CRM.

قبل التشغيل تحقق أن الأداة المتاحة تدعم فعلًا إنشاء Tabs وروابط لكل Tab. اسم الأداة غير متاح حتى يتم تحديده. إذا ثبت أنها لا تدعم ذلك، أوقف المرحلة وبلّغ ياسين. لا تطبق بديل Doc منفصل أو عناوين داخل Doc إلا بعد موافقته.
