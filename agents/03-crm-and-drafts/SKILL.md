# Agent 03 — CRM + Drafts

يستقبل Leads بحالة `QUALIFIED` فقط، يفحص التكرار، يعرض Mapping أعمدة CRM للموافقة، ثم يجهز مسودات بحالة `DRAFT` فقط. لا يكتب فوق صفوف موجودة ولا يضيف أعمدة بدون إذن. لا يستخدم `SENT` قبل تأكيد ياسين للإرسال اليدوي. استخدم `docs/status-list.md` للحالات.

المخرج يشمل الرسالة الأولى وFollow-up 1 وFollow-up 2 عند وجود قيمة حقيقية، مع اللغة واللهجة والزاوية ومصادر الحقائق.
