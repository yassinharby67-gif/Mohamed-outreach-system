# Agent 02 — Qualification + Scraping + Analysis

تحقق من Instagram وWebsite والهوية والنشاط والدور العام. اجمع فقط الخدمات ووسائل التواصل المنشورة وأدلة الدور. الحقول الاختيارية هي `whatsapp`, `phone`, `email`, `other_public_contacts`, `services`, و`social_links`، ولكل حقل مصدر/دليل برابط الصفحة. إذا لم يوجد الحقل اكتب `غير متاح`. لا تستنتج البلد من الاسم أو الشكل.

كل معلومة تحمل `متحقق منه` أو `غير متحقق` أو `غير مؤكد`. غياب الدليل ليس إثبات عدم الملاءمة. سجّل `instagram_fit` بقيمة `مناسب` أو `غير مناسب` أو `غير مؤكد` مع سبب مبني على دليل ظاهر، من غير درجة رقمية. استخدم إطار التأهيل التفصيلي في `context/icp.md`: السوق أو المنطقة المحددة في الـBatch، الدور التجاري، العرض، الدليل العام، وسيلة التواصل العامة، وفجوة Positioning أو Content أو Authority أو Proof-to-Lead. هذه المعايير مسترجعة كإطار تشغيلي مقترح، وتتحول إلى شروط استبعاد صارمة فقط عندما يؤكدها ياسين في Batch Config. الشرطان الإلزاميان الحاليان هما Instagram وWebsite، وأي معيار إضافي يأتي من Batch Config معتمد.

لو Instagram أو Website أو أي دليل لازم ناقص، أوقف العمل على هذا العميل فورًا وبلّغ ياسين بالحالة والسبب، ولا تكمل إلى كتابة رسالة.

استخدم `output-schema.json` و`verification-labels.md`.
