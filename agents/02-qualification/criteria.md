# Criteria

## Hard Gates الآن

- Instagram موجود ويمكن التحقق منه.
- Website موجود ويمكن التحقق من علاقته بالـLead.

## Instagram Fit

المخرج يستخدم `مناسب` أو `غير مناسب` أو `غير مؤكد` مع سبب وأدلة ظاهرة. معايير الملاءمة التفصيلية يحددها ياسين في Batch Config؛ لا توجد درجة رقمية ولا حدود مخترعة.

إذا غاب Instagram أو Website أو دليل لازم، أوقف العميل وبلّغ ياسين فورًا.

## غير محسوم

الدور، المنطقة، حجم المتابعين، نوع الإعلانات، الميزانية، وProof إضافي لا تتحول إلى Gates إلا إذا ظهرت في Batch Config معتمدة.
